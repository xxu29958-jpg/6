# 溪谷 · 微缩活体世界（V4.7 源码）

零依赖单页 Canvas 2D 微缩活体世界：手绘透明 PNG 资产 + 前端动态合成（「插画负责美，前端负责活」）。

## 运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
# 调试时刻：http://localhost:8000/#t=0.475 （0.3=白昼 0.475=黄昏 0.62=蓝调 0.8=夜）
```

## 结构

| 文件 | 职责 |
|---|---|
| `js/world.js` | 世界注册表：资产锚点/bbox、山脊轮廓线、溪流/水潭/瀑布配准、居民路径图（节点+边+途经点+BFS 下一跳表） |
| `js/layers.js` | 分层渲染：L0 烘焙底座、far 远山视差层（脊线蒙版切割）、边缘镜像羽化带、接触影、Y-sort 场景合成、视觉水像素掩码 |
| `js/dynamic.js` | 动态层：溪光/瀑布/涟漪/鱼/炊烟/薄雾/萤火虫/秋千/落叶/黄昏光池/夜晚辉光（全部粒子对象池，rAF 零分配） |
| `js/residents.js` | 居民状态机（idle/walk/sit/chat/swing/home…）+ routeTo 沿路网 BFS 寻路 + 脚底入水断言 + 斗篷小人程序绘制 |
| `js/camera.js` | 响应式相机：视口取景预设（同世界不同 Camera，非 scale）、拖动弹簧回弹、pinch clamp、视差、视野硬约束 |
| `js/daynight.js` | 150s 昼夜循环 8 段关键帧插值（清晨→正午→午后→黄昏→蓝调→夜→深夜→黎明前） |
| `js/interaction.js` | 交互：点水涟漪鱼散/点树摇落/点房探头/点居民推近/拖动/捏合 + 右下角三控件 + WebAudio 程序化音景（默认关） |
| `js/main.js` | 预加载 → 烘焙 → 主循环 → 分层合成管线 |
| `js/util.js` | 数学/确定性随机/颜色/Catmull-Rom/折线测度 |

## 注意

- `assets/*.png`（15 张手绘透明资产 + 地形盘，约 18MB）未包含在本仓库——推送通道不支持二进制。完整可运行包见对话中交付的 `xigu-world-src.zip`。
- 所有世界坐标 = 地形盘像素 2048×1088；资产放置约定 = alpha 紧致 bbox 底部中心锚定。
- 配准参考表（资产锚点/溪线/瀑布矩形/相机预设）在 `design/v4-config.md`（随 zip 提供）。
